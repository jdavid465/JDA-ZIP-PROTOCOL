# 🛡️ Security Policy

## Supported Versions

We actively issue security updates and patches for the following versions of the **JDA-ZIP Protocol** and its reference implementations:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The JDA-ZIP Protocol project takes the security of its implementation and data integrity seriously. If you believe you have discovered a security vulnerability, please **do not open a public GitHub Issue**.

Instead, follow these steps to report it responsibly:

1. **Private Disclosure:** Use the GitHub **"Report a vulnerability"** feature under the **Security** tab of this repository.
2. **Details to Include:**
   * A description of the vulnerability and its potential impact.
   * Step-by-step instructions (or a proof-of-concept payload) to reproduce the issue.
   * Any potential mitigations or fixes you might suggest.

---

## Response Timeline

* **Initial Acknowledgment:** Within **4 days** of receiving your report.
* **Assessment & Fix:** We aim to evaluate and patch verified security flaws within **15 business days**.
* **Public Announcement:** Once a patch is released, we will publish a Security Advisory giving proper credit to the reporter (unless you prefer to remain anonymous).

Thank you for helping keep the JDA-ZIP Protocol safe for the open-source community!
